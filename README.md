# 净水助手 · WaterCalcMod

《Probably Stolen（深空当铺：可能是偷的）》的净水计算 mod。

在游戏原生的净水器面板里，直接告诉你这瓶水该怎么接、怎么过滤、要放几片药、跑几晚、出来多少、纯度多少、能赚多少。不是网页计算器，是长在游戏里的像素风面板。

**版本：1.0** ｜ **适用游戏版本：0.46** ｜ **作者：qixian**

---

## 功能

### 接水方案

- 直接给出「接 X mL」，按你实际使用的容器和滴灌粒度计算，不会出现接不到的理想数字。
- 已有水也能算：当前瓶里有多少水、什么纯度，直接接着往下做。
- 可以设置水源、目标纯度、前置/后置步骤、海德拉，方案会按你的设置走。

### 三档一键推荐

- **自定义**：按当前设置，优先给 0 晚达标方案；0 晚不可行时再给一晚。
- **效率**：尽量把容器装满，适合走量。
- **性价比**：按现有药片、滤棉等库存和成本，决定要不要加药片、加几片。

推荐会区分 0 晚、一晚和多晚：0 晚达标优先，其次一晚，多晚只在前面做不到时使用。

**0 晚优先**：只要存在达标的 0 晚方案，主方案就固定优先 0 晚；需要过夜的方案继续保留在「更多方案」，不会第二天刷新时把 0 晚方案顶掉。

### 步骤会跟着你做

- 步骤栏会显示过滤棉、药片、紫外、混水、净化器、过夜等剩余步骤。
- 药片按你**实际放下的片数**推进，不会放 3 片还卡在 2 片，也不会第 4 片突然跳到完成。
- 关掉机器再打开，当前方案和已完成的步骤会保留，不会重新叫你接水。
- 点另一台机器的「净水助手/接水」图标时，方案会切到那台机器并立即重算，不会把上一台的产出和步骤留在界面上；方案锁定在哪台机器，换机器后一定重算。
- 绿点选中的机器优先于另一台机器的窗口焦点，主页的容器、水源、产出和步骤都按同一台算。
- 切换已有机器窗口时按游戏自己的窗口激活状态（`PixelWindow.focusStamp`）跟进；首次打开窗口仍不会自动选台。
- 选中机器时会复用右键读取的判定，直接按这台机器槽里的实际水刷新主页和方案，但不会跳到计算页。
- 绿点点选和直接点机器面板走同一个切换入口，避免绿点有概率停在旧方案。
- 把容器从机器里拿走、或取消选中机器后，方案会自动取消，不会继续显示旧方案。

### 混水页

- 看当前这瓶水最多还能兑多少基础水/沟渠水/铁锈水。
- 直接显示混合后的水量和纯度，以及需要几步。
- 主界面和混水页使用同一套方案，不会两边给出不同结果。
- 混水方案不再按当前容器容量截断，按目标纯度把可兑水全部算入；超过 6L 时按分瓶/分次倒执行。
- 净水器槽里已有液体，即使还没点选机器，也能在混水页读到。
- 点选机器后，混水页按选中的那台机器读，不会串到另一台；扫描只排掉选中的同一瓶，不再把其他机器槽里的水整批隐藏。

### 收益与成本

- 显示卖水收入、药片/滤棉/海德拉/电费等成本、净赚、每升价格。
- 多过一晚就多算一晚电费，不把两晚的成本按一晚算。
- 不读取客人预算、客人历史或钱包，也不会按客人钱包砍你的水量。

### 界面与操作

- 游戏原生像素面板，风格和游戏内机器界面一致。
- 默认 **F7** 呼出面板，可在「主菜单 → 模组 → 净水助手 → 齿轮」里改快捷键。
- 净水器窗口标题栏的水滴按钮是**接水**，不是重新计算。
- 内置书页式使用说明。

## 安装

### 创意工坊版

1. 在 Steam 创意工坊订阅「净水助手」。
2. 进入游戏，在主菜单的「模组」里选中「净水助手」，审核并启用。
3. 进游戏后按 **F7** 打开面板。

### 本地版

1. 把 `WaterCalcMod` 文件夹放到 `游戏安装目录\Mods\`。
2. 在游戏主菜单「模组」里启用。
3. 按 **F7** 打开面板。

> 本地版和创意工坊版使用同一个 ID，不能同时启用。装了两个文件夹的话删掉一个。

## 说明

- 只适配游戏版本 **0.46**；游戏更新后可能需要重新适配。
- 不修改存档、不联网、不改变游戏内水质/价格数据，只做本地计算和界面显示。
- 方案锁定后，倒水、接水、过夜不会随便改方案；换机器、改设置或按模式键会重新计算。
- 如果界面显示和游戏内数字不一致，以游戏内实际面板为准，并带上截图/复现步骤反馈。
