## 5. 边界与失败返回

- 库存 0 片：`AutoSolve` 不返回带药片方案；`no_tablet_stock0` 通过。
- 无限库存：t 不受库存限制，但不超 6 片。
- 50 L 目标 99.00 在无滤棉/低质量水等极端参数下 `okFalse`，这是预期不可行，不是崩溃。
- `zero_filter_50` / `hydra_50` 目标不可达时返回 `okFalse`；不伪造可行方案。
- 两晚电费按 `nights` 计：`WaterPlan` 4L 两晚 cost9.00（含两晚电费），不再只收一晚。
