## 上传步骤（Steam 创意工坊）

1. 游戏内 → 主菜单「模组」→ 选中「净水助手」→ 右上「上传到创意工坊」（或在同界面用官方的上传入口）。
2. **上传的必须是 `dist/WaterCalcMod/` 里的 Release 版 dll**（不是 DEV）。核对：
   - `WaterCalcMod.dll` 约 **278,528 B**
   - `manifest.xml` 的 `<Capabilities></Capabilities>` 是空的
   - 二进制里搜不到 `ctl.`、`log.txt`、`Desktop`（可用 `grep -ac` 自查，全为 0）
3. 上传前先在游戏里 **F8 控制台跑一次** `mod-scan watercalc_assistant`：
   - `declared` 应为空
   - `detected` 应为空
   - 不应出现 `DEPRECATED` 行
   任何一条不满足，说明拿错包了（很可能是 DEV 构建）。
4. 上传时填下面的文案；缩略图建议用面板截图（1280×720 或 512×512）。

## 工坊文案（可直接粘贴）

**标题**

```
净水助手 · 接水/过夜/纯度 一键算清
```

**一句话简介**

```
把「这瓶水接多少、跑几晚、出来多少、每升多少钱」直接算给你看，并按你的模式给出推荐方案。
```

**详细说明**

```
【这是什么】
一个纯计算 + 显示的原生小工具。它不刷物品、不改存档、不联网，只是把净水器相关的真实公式算给你看，
并且把建议直接叠在原版净水器窗口和一块原生风格面板上。

【怎么用】
· 打开净水器 → 窗口标题栏会多出两个小图标：
    - 水滴图标 = 接水（和原版接水按钮的作用一致）
    - 「效率(无视容器)」= 按净水器 10 L 硬上限算一晚能吃多少
· F7 打开面板（快捷键可在「模组」菜单的齿轮面板里改）：
    - 接水方案：读今天真实的水龙头水质，告诉你「接 X mL · 一晚最多能处理 Y mL」
    - 已有水方案：容器里已经有水（自己兑的、混过的都行）时，按这瓶水真实的六项配比算「过几晚 + 几片药片 → 出多少 mL、多少纯度」
    - 三种模式：自定义 / 效率（先把容器拉满）/ 性价比（每升最省）
    - 前置 / 后置 / 海德拉（便携净水器）都能参与计算
· 手册书页里也有同样的说明，走游戏原生书页。

【口径说明】
界面数字与游戏内面板逐位对齐：水量按 μL 内部值向上取整显示（游戏最小单位 0.1 mL），
药片「满瓶才挤 15 mL、逐片结算」，过滤棉按 3 L/份计耐久，紫外灯按工具不消耗耐久。
海德拉按游戏实际公式：1 点耐久处理 100 mL，满 330 点 = 33 L。

【不支持】
· 不推荐超过一晚的方案（避免把一瓶水拖成两天）
· 未解锁的水龙头不会被凭空接水，会明确提示未解锁
· 只覆盖净水器相关公式；手册页里的参考数字不随机器加成实时变化

【权限】
零。本 mod 不读写的任何外部文件、不联网、不使用已弃用的反射能力，因此不会触发 2026-12-10 起的能力拒绝。

【说明】
原作者已停止维护，源码与全部逆向笔记已开源（见工坊页面的源码链接），欢迎接手改进。
```

**标签建议**：`模组` `工具` `中文` `净水` `计算器`

4. 没有图标（`Icon` 字段未使用），可加。
