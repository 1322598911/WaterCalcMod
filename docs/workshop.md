## 工坊文案（可直接粘贴）

**标题**

```
净水助手 · 接水/过夜/纯度 一键算清
```

**一句话简介**

```
把「这瓶水接多少、跑几晚、出来多少、每升/每晚赚多少」直接算给你看，并按你的模式给出推荐方案。
```

**详细说明**

```
【这是什么】
一个纯计算 + 显示的原生小工具。它不刷物品、不改存档、不联网，只是把净水器相关的真实公式算给你看，
并且把建议直接叠在原版净水器窗口和一块原生风格面板上。

【怎么用】
· 打开净水器 → 窗口标题栏会多出两个小图标：
    - 水滴图标 = 接水（和原版接水按钮的作用一致）
    - 「效率(无视容器)」= 按净水器 10 L 硬上限算一晚能吃多少
· F7 打开面板（快捷键可在「模组」菜单的齿轮面板里改）：
    - 接水方案：读今天真实的水龙头水质，告诉你「接 X mL · 一晚最多能处理 Y mL」
    - 已有水方案：容器里已经有水（自己兑的、混过的都行）时，按这瓶水真实的六项配比算「过几晚 + 几片药片 → 出多少 mL、多少纯度」
    - 三种模式：自定义 / 效率（先把容器拉满）/ 性价比（按库存药片影子价选 0 片或加片）
    - 前置 / 后置 / 海德拉（便携净水器）都能参与计算
· 手册书页里也有同样的说明，走游戏原生书页。

【1.0.2 更新】
· 性价比自动档加入「药片影子价」：同进水量、同晚数下，按库存给每片药定价——
  库存 1 片 = 15 元/片，2–3 片 = 10 元/片，4 片以上 / 无限 = 6 元/片。
  比较「净赚 − 影子价 × 药片数」，0 片已达标时，加片必须多赚超过这笔钱才推荐；
  加片跨到更高售价档且现金净赚更高时，优先保留高售价档。
· 一晚优先：默认最多 2 晚，能一晚处理完就只跑 1 晚；两晚只在「一晚做不到」时用，
  不让第二晚空跑占产能。50 L + 足够滤棉/海德拉可 2 晚出约 49.6 L；44 L 一晚约 42 L，
  不会为了「一晚 44 / 两晚 50」把可用水硬限制成 11 L。
· 两晚电费按实际晚数计：旧版混水候选只收一晚电费，本版已改为「两晚收两晚」。
· 主页 / 计算页 / 混水页统一写入同一组药片影子价；不会一边按影子价、一边按旧总利润。
· 核对机器映射：界面读的是 performance bonus（性能加成），它加进净化预算；
  标题栏「效率(无视容器)」是 UI 模式，不是机器「效率」词条。效率词条只影响耗电。
· 不读取客人预算、客人历史或当前客人钱包；不按客人钱包裁剪容量/晚数。
· 水商手册第 6 页改为新口径：全成本含药片 6/片、滤棉 25/400 耐、海德拉 325/300 耐、电 4 度/晚；
  并写明库存影子价与「0 片已达标才比较加片」的触发条件。

【口径说明】
界面数字与游戏内面板逐位对齐：水量按 μL 内部值向上取整显示（游戏最小单位 0.1 mL），
药片「满瓶才挤 15 mL、逐片结算」，过滤棉按 3 L/份计耐久，紫外灯按工具不消耗耐久。
海德拉按游戏实际公式：1 点耐久处理 100 mL，满 330 点 = 33 L。

【不支持】
· 不推荐超过 2 晚的方案；2 晚只在一晚做不到时出现，不默认拖时间
· 未解锁的水龙头不会被凭空接水，会明确提示未解锁
· 只覆盖净水器相关公式；手册页里的参考数字不随机器加成实时变化

【权限】
零。本 mod 不读写的任何外部文件、不联网、不使用已弃用的反射能力，因此不会触发 2026-12-10 起的能力拒绝。

【验证边界】
1.0.2 已通过离线数学回归（2/4/6/20/44/50 L、铁锈/读取/混合水、库存 0/1/2/4/9、三种影子价）
与 Release/DEV 双构建 0 error；尚未在本机游戏里逐页点验 UI。若实机显示与描述不一致，
请带 F8 日志反馈，以游戏内实际面板为准继续修。

【说明】
原作者已停止维护，源码与全部逆向笔记已开源（见工坊页面的源码链接），欢迎接手改进。
```
